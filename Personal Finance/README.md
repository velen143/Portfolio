### Project : Personal Finance & Expense Analysis Dashboard

### Overview

Proyek ini melakukan analisis data keuangan untuk mengetahui pola pendapatan, pengeluaran, tabungan, serta kondisi pengelolaan keuangan berdasarkan kategori pengeluaran, essential dan discretionary spending, serta periode pengamatan. Analisis dilakukan untuk memberikan gambaran mengenai kondisi cash flow dan membantu mengidentifikasi pola pengeluaran yang dapat menjadi bahan evaluasi pengelolaan keuangan.

### Tools

- Microsoft Excel
- Power BI
- DAX

### Alur Kerja

1. **Data Understanding (Pemahaman Data)**\
   Tahap awal dilakukan dengan memahami struktur dataset, jumlah data, tipe data, pendapatan, pengeluaran, actual savings, kategori pengeluaran, serta indikator keuangan lainnya.

2. **Data Cleaning (Pembersihan Data)**\
   Proses pembersihan dilakukan menggunakan Microsoft Excel dengan melakukan pengecekan missing value, data duplikat, tipe data, konsistensi format tanggal, serta standardisasi data kategorikal. Data yang telah dibersihkan kemudian digunakan sebagai sumber analisis.

3. **Data Analysis (Analisis Data)**\
   Analisis dilakukan menggunakan Power BI dan DAX untuk menghitung total income, total expense, actual savings, savings rate, essential spending, dan discretionary spending. Analisis juga dilakukan berdasarkan kategori dan periode waktu.

4. **Data Visualization**\
   Hasil analisis divisualisasikan menggunakan Power BI dalam bentuk dashboard interaktif yang menampilkan KPI, tren income, expense dan savings, distribusi pengeluaran berdasarkan kategori, perbandingan essential dan discretionary spending, serta detail keuangan.

### Hasil Analisis

- Income, expense, dan actual savings dapat dipantau berdasarkan periode untuk memberikan gambaran mengenai perubahan kondisi keuangan dari waktu ke waktu.

- Pengeluaran terkonsentrasi pada beberapa kategori utama, sehingga kategori dengan kontribusi pengeluaran terbesar dapat menjadi fokus dalam evaluasi dan pengelolaan anggaran.

- Perbandingan essential dan discretionary spending memberikan gambaran mengenai proporsi pengeluaran untuk kebutuhan utama dibandingkan pengeluaran yang lebih fleksibel.

- Savings rate digunakan sebagai indikator untuk melihat seberapa besar pendapatan yang berhasil dialokasikan menjadi tabungan setelah memperhitungkan pengeluaran.

- Dashboard memungkinkan pengguna melakukan filter berdasarkan bulan dan tahun sehingga analisis kondisi keuangan dapat dilakukan pada periode tertentu.

- Visualisasi interaktif membantu memberikan gambaran yang lebih mudah dipahami mengenai cash flow, pola pengeluaran, dan kemampuan menabung.
