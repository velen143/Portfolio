### Project : Analisis Data Konten Netflix

### Overview 
Proyek ini melakukan analisis data eksplorasi (EDA) pada konten Netflix, menjelajahi tren, pola, dan karakteristik utama film dan acara TV yang tersedia di platform tersebut.

### Tools
* Python
* Pandas
* Matplotlib
* Seaborn
